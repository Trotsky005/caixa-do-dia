# Caixa do Dia

Site de fechamento de caixa e contas a pagar (Areias, Barreiro e Banco).

- `index.html`: a página (publicada pelo GitHub Pages). Grava os dados na planilha do Google "Caixa do Dia – Dados" por meio do Apps Script.
- `apps-script/Code.gs`: o servidor. Fica colado no Apps Script da planilha (Extensões › Apps Script), implantado como App da Web.
- `supabase/`: versão com Supabase (não usada no momento).

Senhas de acesso: aba **Senhas** da planilha, coluna C.
