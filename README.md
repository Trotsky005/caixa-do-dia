# Caixa do Dia

Site de fechamento de caixa e contas a pagar (Areias, Barreiro e Banco).

- `index.html`: a página (publicada pelo GitHub Pages).
- `supabase/functions/api/index.ts`: o servidor (Supabase › Edge Functions › api).
- `supabase/schema.sql`: estrutura do banco (Supabase › SQL Editor).

Senhas de acesso: Supabase › Table Editor › senhas.
